# First-stage network boot (BIOS + UEFI)

`build-tftp-stage.sh` builds the TFTP tree into `${PXE_LOCAL_ROOT}/tftp-stage`
(not served over HTTP; nginx must return 403 for `/pxe/tftp-stage/`):

| File (TFTP path) | What |
|---|---|
| `ipxe/undionly.kpxe`, `ipxe/snponly.efi` | iPXE 2.x first stage (BIOS / UEFI x64), built from upstream source by `boot/ipxe/build.sh` into `${PXE_DOWNLOADS}/ipxe` (embedded script: DHCP, then `chain tftp://<next-server>/ipxe/boot.ipxe`) |
| `ipxe/boot.ipxe` | **the single boot menu**, generated by `./simple-pxe ipxe-menu` (`boot/gen-boot-ipxe.sh`): Debian installers (+firmware), Debian diskless, FreeBSD 15.1, legacy GRUB, iPXE shell, reboot; optional per-machine script `ipxe/mac-aa-bb-cc-dd-ee-ff.ipxe` runs first |
| `grub/i386-pc/core.0`, `grub/x86_64-efi/grubnetx64.efi` | GRUB loaded straight by the firmware (prefix `/grub`); no longer used by the default DHCP rules |
| `grub/i386-pc/core-ipxe.0`, `grub/x86_64-efi/grubnetx64-ipxe.efi` | the same GRUB when started from the iPXE menu entry "Legacy GRUB menu (fallback)" |
| `grub/grub.cfg`, `grub/grub.cfg.d/default` | read by all GRUB images; `default` points at the HTTP `root.menu` |
| `freebsd/<ver>_amd64/pxeboot`, `.../loader_pxe.efi` | FreeBSD BIOS / UEFI loaders with the NFS root patched in (`prepare.d/freebsd.sh`); only the versions in `FREEBSD_VERSIONS` are staged |

## One menu: how it works

    firmware PXE -> DHCP -> ipxe/undionly.kpxe (BIOS) | ipxe/snponly.efi (UEFI)
      -> embedded script: DHCP again (iPXE's own), chain tftp://<next-server>/ipxe/boot.ipxe
      -> menu "ncosbit Network Boot": choose -> kernel+initrd (HTTP) or FreeBSD loader (TFTP) boots directly

* Entries are generated from the data tree and config, not hand-written: Debian from
  `${PXE_LOCAL_ROOT}/debian/release-list` limited to `PXE_IPXE_DEBIAN_SUITES` (default
  `DEBIAN_LOCAL_SUITES`), kernel/initrd from the local netboot cache or, if absent or
  `DEBIAN_USE_LOCAL_MIRROR=1`, from the effective mirror (same decision as `menu.d/debian.sh`),
  kernel parameter `url=<PXE_HTTP_ROOT>/debian/preseed.txt`, `+firmware` adds
  `firmware/<codename>/firmware.cpio.gz` as second initrd; diskless as `menu.d/diskless-debian.sh`;
  FreeBSD from `FREEBSD_VERSIONS` (UEFI: `loader_pxe.efi`, BIOS: `pxeboot`, chosen by `${platform}`).
* Default entry: the first Debian entry (trixie installer) after 10 s (`PXE_IPXE_DEFAULT`,
  `PXE_IPXE_TIMEOUT`, 0 = wait forever). Keys: `1`-`7` in menu order, `g` GRUB, `s` shell, `r` reboot.
* More systems (e.g. a FreeBSD diskless image) are added as fragments in `boot/ipxe/entries.d/`,
  see its README.
* The iPXE binaries: `boot/ipxe/build.sh` (upstream tag `IPXE_REF`, default v2.0.0; config in
  `boot/ipxe/config/general.h`, embedded script `boot/ipxe/embed.ipxe.in`; needs git make gcc
  binutils perl liblzma-dev). Byte-identical on rebuild. Secure Boot must stay off (unsigned).
  `build-tftp-stage.sh` calls it automatically if `${PXE_DOWNLOADS}/ipxe` has no iPXE built that way.

Copy the stage to the TFTP root (`/srv/tftp` for tftpd-hpa):

    sudo rsync -a --delete --chown=root:root --chmod=D755,F644 ${PXE_LOCAL_ROOT}/tftp-stage/ /srv/tftp/

GRUB then loads `(http,<host>)<path of PXE_HTTP_ROOT>/menu/root.menu` over plain HTTP.
Use an IP address in `PXE_HTTP_ROOT` if the DHCP-provided DNS is slow or missing
(GRUB sometimes drops the first DNS query).

## Why FreeBSD is not started from GRUB

* UEFI: GRUB keeps the NIC open exclusively; FreeBSD `loader.efi` then fails with
  "Unable to open network interface 0 for exclusive access: 15". There is no GRUB
  command that releases it (`rmmod efinet` fails: the `chain` module references it).
* BIOS: `kfreebsd` + `kfreebsd_module cd.iso type=mfs_root` loads the ISO and then the
  machine resets (reproduced with FreeBSD 14.5 and 15.1 in QEMU; 14.5 is no longer published); GRUB cannot chain
  `pxeboot` because it needs the PXE stack as the firmware left it.

FreeBSD is booted directly by the firmware (DHCP filename) or by the iPXE menu. The NFS root is
patched into the loaders, so no DHCP root-path option is needed; the NFS server is the
DHCP `next-server`. Boot flow: loader (TFTP) -> kernel and `/boot` over NFS (UDP, v3) ->
kernel mounts the same NFS root -> `rc.initdiskless` mounts `cd.iso` -> installer.

NFS export (`/etc/exports`): `<PXE_NFS_ROOT> 10.20.0.0/16(ro,no_root_squash,no_subtree_check,insecure)`
plus `udp=y` / `vers3=y` for nfsd (`/etc/nfs.conf.d/pxe-udp.conf`).

## DHCP (dnsmasq syntax; `next-server` is the TFTP + NFS host)

| Client | Condition | `filename` |
|---|---|---|
| iPXE (option 175) | any, unless FreeBSD-tagged | `ipxe/boot.ipxe` (the embedded script loads it itself; the DHCP filename is not needed but keeps older iPXE working) |
| BIOS (option 93 = 0) | default | `ipxe/undionly.kpxe` |
| UEFI x64 (option 93 = 7 or 9) | default | `ipxe/snponly.efi` |
| FreeBSD 15.1, BIOS | per machine (MAC tag, optional) | `freebsd/15.1_amd64/pxeboot` |
| FreeBSD 15.1, UEFI x64 | per machine (MAC tag, optional) | `freebsd/15.1_amd64/loader_pxe.efi` |
| Without iPXE (Linux only) | BIOS / UEFI | `grub/i386-pc/core.0` / `grub/x86_64-efi/grubnetx64.efi` |

    dhcp-match=set:bios,option:client-arch,0
    dhcp-match=set:efi64,option:client-arch,7
    dhcp-match=set:efi64,option:client-arch,9
    dhcp-match=set:ipxe,175
    dhcp-host=aa:bb:cc:dd:ee:ff,set:fbsd151        # machines that should boot FreeBSD 15.1 directly
    dhcp-boot=tag:fbsd151,tag:bios,freebsd/15.1_amd64/pxeboot,,10.20.0.26
    dhcp-boot=tag:fbsd151,tag:efi64,freebsd/15.1_amd64/loader_pxe.efi,,10.20.0.26
    dhcp-boot=tag:!fbsd151,tag:ipxe,ipxe/boot.ipxe,,10.20.0.26
    dhcp-boot=tag:!fbsd151,tag:!ipxe,tag:bios,ipxe/undionly.kpxe,,10.20.0.26
    dhcp-boot=tag:!fbsd151,tag:!ipxe,tag:efi64,ipxe/snponly.efi,,10.20.0.26

The MAC-tagged lines are optional: without them FreeBSD is chosen from the iPXE menu.

## Testing

`qemu-smoke.sh bios|uefi` boots the GRUB images directly in QEMU/OVMF (user-mode
networking) and checks that the menu is reached over HTTP.

`qemu-net-test.sh` is the full-stack test: private tap + dnsmasq with the DHCP rules
above, real TFTP/HTTP/NFS; see the header of the script (`setup`, `run`, `teardown`).

`nginx/pxe-location.conf` is the nginx snippet that serves `PXE_LOCAL_ROOT` at `/pxe/`
(include it in the `:80` server and, optionally, the HTTPS server).
